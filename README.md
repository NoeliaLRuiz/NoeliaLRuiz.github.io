# noelialruiz.github.io

Mi sitio personal: proyectos de datos, experiencia, formación y certificados.

**Ver el sitio:** https://noelialruiz.github.io

| Archivo | Qué es |
|---|---|
| `index.html` | La página completa (HTML y CSS en un solo archivo) |
| `images/` | Mi foto y las imágenes de las tarjetas de proyecto |
| `files/cv-noelia-leon-ruiz.pdf` | Mi CV en PDF |
| `_fuentes/cv.html` | La fuente del CV; GitHub Pages no publica las carpetas que empiezan con `_` |

## Cómo actualizarlo

- **Nuevo proyecto:** copiar un bloque `<article class="proyecto">` de `index.html`, cambiar título, pregunta, resultado, imagen y enlaces, y ponerlo primero si es el mejor.
- **CV:** editar `_fuentes/cv.html` y volver a imprimirlo a PDF con Edge (`--print-to-pdf`) en `files/cv-noelia-leon-ruiz.pdf`.

El diseño de una sola página se inspira en el sitio de [Jon Barron](https://jonbarron.info).
